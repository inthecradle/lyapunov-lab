# 定理2・3の可視化モデル

日本語 | [English](collective-mathematics.en.md)

## 原典と表示の対応

根拠は苫米地英人『進化の5定理』日本語版（2026年7月12日版）の定理2・3、仮定A5・A6、付録A.3・A.4です。

- [原典](https://tomabechi.jp/TomabechiEvolution5theoremsJA.html)

原典の方策式は、定理2では個人評価V_iとΣ_j γ_ij S_ijを積分して最小化し、定理3ではさらにη_i Aを加えた積分の期待値を最小化します。期待値はLUBの位置に関する認識論的不確実性を扱います。画面にはこの方策式を表示し、計算に使用する具体関数と区別します。

付録の合成評価を原典の記号で表示します。

```text
ℒ(x,t)   = Σ_i V_i(x_i,t) + Σ_{i,j} γ_ij S_ij(x_i,x_j)
ℒ_A(x,t) = Σ_i V_i(x_i,t) + Σ_{i,j} γ_ij S_ij(x_i,x_j) + η A(x)
```

V_iをR_iに置き換えたり、組ごとのγ_ijを総和の外へ出したりしません。原典にない個別目標への力κも加えません。

原典は以下の具体関数や速度場を一意に指定していません。実装は原典の評価項を数値化した固定3主体の例であり、原典のargmin問題を解いて最適方策を求めたものではありません。また、原典の全仮定の成立を検証する機能ではありません。

## 数値化に採用した状態・関数

主体iの状態をx_i=(r_i,z_i)、r_i∈ℝ、z_i∈[0,1]²とし、抽象写像をφ_i(x_i)=z_iとします。比較対象は全状態ではなく抽象写像の像です。個人変数の区間I=[−1,1]を使い、次の非負C¹関数を採用します。

```text
V_i(x_i) = ½ dist(r_i,I)²
S_ij(x_i,x_j) = ½ ||z_i−z_j||²
A_i(x_i) = ½ ||z_i−L||²
A(x) = Σ_i A_i(x_i)
```

Iはこの具体化でV_i=0となる個人変数の区間です。集団全体のShared-TCZの閾値集合とは異なります。領域内の異なるr_iは保持され、表象の一致は全状態の同一化を意味しません。

初期設定はr(0)=[0.8, −0.6, 0.5]で、全主体が個人のV_i=0の領域内にいます。一方、共有表象はz_1(0)=(0.8,0.2)、z_2(0)=(0.2,0.8)、z_3(0)=(0.35,0.35)と異なります。既定の結合γ_ij=0.8では、初期の個人評価の和は0、不一致費用は0.936です。定理2の合成評価ℒ(0)=0.936は閾値θ=0.1を超えます。つまり、各主体が個人的に快適でも、集団全体の共有条件を満たしているとは限らない例です。個人状態は再生中も初期値を保ちます。個人領域外の減衰は、数値テストで別の初期条件を明示して検証します。

固定された世界W_i∈[0,1]²に対して、成分ごとの順序を採用します。

```text
u ≼ v ⇔ u₁≤v₁ かつ u₂≤v₂
L = LUB(W₁,W₂,W₃) = (max_i W_i₁, max_i W_i₂)
```

Lは各W_iの上界であり、任意の共通上界Uに対してL≼Uです。例として(0.8,0.2)と(0.2,0.8)のLUBは(0.8,0.8)です。平均(0.5,0.5)は上界ではなく、(1,1)は上界ですが最小ではありません。この数値順序は説明用の具体化であり、人の抽象度の実測尺度ではありません。

LUBは既知で固定とし、不確実性がない場合として期待値を評価します。原典の期待値記号を削除する一般化ではありません。

画面の初期条件編集では、主体の初期表象z_i(0)と世界W_iを同じ座標に設定します。ドラッグ・矢印キー・数値入力のいずれでも両方を更新し、LUBを再計算して時刻0に戻します。これは実験条件を設定する操作であり、再生中にW_iが動くという仮定ではありません。各軌道の計算ではW_iとLUBを固定します。

## 結合係数と二重和

実装のgamma=[γ₁₂,γ₁₃,γ₂₃]は非負の対称係数を表します。γ_ji=γ_ij、S_ji=S_ij、S_ii=0です。原典のΣ_{i,j}では両方向を数えるため、計算は次のとおりです。

```text
Σ_{i,j} γ_ij S_ij = 2 Σ_{i<j} γ_ij S_ij
```

各スライダーの値はγ_ijそのものです。無向辺を1回だけ数える表現への読み替えや、隠れた1/2倍はしません。

APIのindividualはΣV_i、socialはΣijγ_ijS_ij、abstractionはη_eff A、totalは合成評価です。定理2ではη_eff=0、定理3ではη_eff=ηとします。pairCostsは重みを掛ける前のS_ij、personalCostsはV_i、abstractionCostsはA_iです。

結合が0の組でも不一致は測定できるため、disagreement=max_{i<j}||z_i−z_j||は重み付き費用socialと別に表示します。targetDistance=max_i||z_i−L||もη=0の場合を含めて測定します。

## 採用した速度場と散逸

合成評価の負の勾配を速度とする、次の決定論的な閉ループを採用します。これは数値可視化の設定であり、原典の最適方策の解ではありません。

```text
ṙ_i = −(r_i−clip_I(r_i))
ż_i = −2 Σ_j γ_ij(z_i−z_j) − η_eff(z_i−L)
ℒ̇（または ℒ̇_A）= −Σ_i dist(r_i,I)² − Σ_i ||∇_{z_i}ℒ（または ℒ_A）||² ≤ 0
```

速度の係数2は、対称な二重和を微分した結果です。個人領域外からは境界に漸近し、有限時間での厳密な境界到達は一般にありません。zの正方形は前方不変です。描画時の切り詰めで軌道を正方形へ戻す処理はしません。

## 閾値集合と原典の結論

原典は合成評価F=ℒまたはℒ_Aについて、閾値集合Ω_θ={x:F≤θ}の外側で次の比較不等式を扱います（定理3ではθ_A）。

```text
Ḟ ≤ −α(F−θ)
(F(t)−θ)₊ ≤ (F(0)−θ)₊ exp(−αt)
F(t) ≤ θ + (F(0)−θ)₊ exp(−αt)
```

θ>0の集合に近づくことだけでは、不一致や抽象化残差が厳密に0へ収束するとはいえません。集合内では正の結合に対するS_ij≤θ/γ_min、定理3ではA≤θ_A/ηという評価が得られます。原典のゼロ整合の議論には、閾値を0へ近づける場合や追加の正則性条件があります。

画面では閾値線、Fの比較上限、正部分残差(F−θ)₊を表示します。thresholdReachedはF≤θを表し、S_ij=0やA=0の判定ではありません。θを変えてもこの具体モデルの速度場・軌道は変わりません。

この具体モデルはさらに強いḞ≤−αFを満たします。L_γを結合グラフのLaplacian、H=2L_γ+η_eff I₃、Λ₊をHの正の固有値の集合として、α=2 min({1}∪Λ₊)を使います。零固有値の方向には費用がないため、上限の最小値に含めません。H=0ならα=2です。

APIのboundは上記の閾値付き合計上限、residualは(F−θ)₊、residualBoundはその指数上限です。具体モデルでは任意の正の閾値に有限時間で入りますが、原典の閾値付き不等式だけから有限時間到達は主張しません。

## 原典の仮定と具体モデルの収束先

原典のA5は結合グラフの連結性と結合強度の正の一様下界を要求します。分断設定はこの仮定を外す比較実験です。定理3のη=0も抽象化項を除く比較であり、不確実性の消失とは異なります。

この対称勾配流での収束先は次のとおりです。

- η_eff=0、連結：全表象が初期表象の算術平均へ収束します。平均をLUBとは呼びません。
- η_eff=0、分断：連結成分ごとの初期平均へ収束します。F→0でも成分間の不一致は残り得ます。
- η_eff=0、全γ=0：表象は初期位置に留まります。
- η_eff>0：全員に同じ既知Lへの引力が働く具体化により、分断時も全表象がLへ収束します。これは原典の連結性仮定を除去する主張ではありません。

これらの平均・LUBへの厳密な収束は、採用した具体関数と速度場から得られる性質です。原典の一般的な方策式だけから同じ軌道が決まるわけではありません。collectiveGuaranteesのconnectedは正のγからなるグラフの連結性、alignment/lubはこの具体モデルの収束判定です。

## 任意時刻の評価と検証

個人変数はr_i(t)=clip_I(r_i(0))+(r_i(0)−clip_I(r_i(0)))exp(−t)で評価します。表象はż=−Hz+η_eff Lを平均方向とその直交空間に分け、対称行列の固有モードを指数関数で評価します。小さい指数にはexpm1を使い桁落ちを抑えます。時間積分の累積誤差がなく、巻き戻しても同じ時刻の状態を再現します。

単体テストでは、全9組を独立に列挙した二重和、係数2を含む速度場、評価値の時間微分、異なるγ・分断での上限、閾値内外の比較、θによる軌道の不変性、平均とLUBの区別を確認します。ブラウザテストでは係数ごとの操作、表示値、閾値・不一致の区別、再生・逆シーク、定理の切替を確認します。

表示専用のテストでは、共有頂点の再利用、変形終点と費用地形の幾何学的な一致、奥行きによる描画順、変形中の有限な座標・配色、谷がない場合の平面への移行を確認します。ブラウザでは導入中にモデル時刻・評価値が変わらないこと、一時停止・再開・スキップ・再再生、再生終了後のやり直し、ポップアップの開き直し、PCからモバイルの2D／3D表示への移行も検証します。

対象は固定3主体、固定世界、非負の対称結合、既知LUB、決定論です。認識論的不確実性の分布、動的なLUB、非対称結合、一般の意味世界の束、HJBによる最適方策の求解は実装していません。パラメータ変更時は新しい固定条件の軌道を時刻0から表示します。

## 3D地形と原典の谷の図示

原典の「定理1→2→3の接続」図に合わせ、定理1と同じ周囲の平面と中央のくぼみを使い、全3主体と軌跡を同じ地形上に表示します。状態の次元は2のままで、縦方向は費用の表示です。初期表示は3Dです。

### 定理2：固定された不一致費用Qの地形を表示する

結合グラフのLaplacianをL_γ、初期表象の算術平均をm₀、L_γの第2固有値をλ₂とします。対称結合の定理2では平均が保存されます。既存の社会的費用は次の関係を満たします。

```text
social = Σ_{i,j} γ_ij S_ij = Σ_{i<j} γ_ij ||z_i−z_j||²
Q(q) = λ₂ ||q−m₀||²
Σ_i Q(z_i) ≤ social
```

3本の結合係数がすべて同じγならλ₂=3γで等号が成立し、Qは社会的費用を共通の谷に分解した厳密な表示になります。初期設定γ=.8ではλ₂=2.4です。結合係数が異なる場合は社会的費用の下界を表示していると明記します。実際のsocialと合成評価ℒは時間グラフで確認できます。

定理2は最初から固定された不一致費用Qの地形を表示します。個人の谷が合流して深くなる導入は使用しません。Qは個人評価V_iを含まないので、個人の谷との深さ比較には使いません。Qは表示に使う量で、制御方策や速度場へ加算しません。また、原論文が絶対的な平均位置を谷底として指定しているわけではありません。この具体的な対称結合モデルで初期平均が保存されることを使った表示です。不均一結合では個々の主体の高さが常に減少するとは限りません。

分断時は連結成分ごとに谷を求めます。「03 集団を分断」の主体1・2には、2人の初期平均m₁₂を中心にQ₁₂(q)=2γ₁₂||q−m₁₂||²の谷を描きます。Q₁₂(z₁)+Q₁₂(z₂)はその組の元の社会的費用と一致します。孤立した主体3の表示費用は0で、谷へ引かれないことを示すため周囲の基準面に配置します。全結合が0の場合のみ谷のない平面になります。これは表示上の区別であり、孤立主体に費用や力を追加しません。

### 定理3：LUBを谷底とする共通の抽象ポテンシャル

既存のA_i(q)=½||q−LUB||²を使い、全3主体を一つの谷に配置します。谷底はLUBでA_i=0です。合成評価ℒ_A全体とは区別し、ℒ_Aは時間グラフで確認できます。η=0でもA_iの定義は残りますが、速度場にLUBへの引力は働きません。

通常画面はA_i、ポップアップは重み付きのηA_iを表示します。η>0なら両者の谷底は同じLUBです。η=0では、通常画面にはA_iの谷が残り、ポップアップのηA_iは全域0の平面になります。表示する費用と高さの正規化を区別し、見た目の谷の深さをηによる費用の大小比較には使いません。

### 定理1と共通の高さ圧縮

縦方向には定理1と同じcompressedHeightを使います。

```text
表示高さ = −210 max(0, 1 − 費用/(.85 M))³
```

Mは表示範囲を決める定数です。費用の小さい部分をくぼみとして見せ、遠方を平面へ滑らかにつなぐ描画変換です。負の表示高さは負の費用を意味しません。導入完了後の図中の数値とdata-heightは元の非負費用を保持し、圧縮後の高さと区別します。説明用の導入中は主体の地形上のdata-heightを付けず、data-display-heightで描画高さを示します。上部の基準面は費用0の面ではありません。

定理2ではM=2.4R²/1.12²（Rは固定描画半径）を用い、γを変えても高さの基準を変更しません。2.4は既定の等結合γ=0.8の第2固有値です。実際のQの係数λ₂は変更後のγから再計算するので、γの差が描画の正規化で相殺されません。不均一結合では、特定の辺を強くしてもλ₂が変わらない場合があります。例えばγ=[0.8,0.8,0.8]と[2,0.8,0.8]ではλ₂=2.4のままですが、実際の不一致費用と軌道は変わります。Qが下界であることと、各主体の実費用を区別します。

カメラ・主体の選択・2D／3D切り替えは、計算結果と地形の意味を変えません。初期位置編集はW_iとLUBを更新して時刻0に戻します。くぼみや等高線を、集団全体の合成評価の閾値集合と同一視しません。原典の概念図の深さに合わせるための追加の力・負の費用・新しい井戸は導入しません。

### 定理3の個人の谷から共通の谷への導入（概念図）

以下の導入は定理3だけで使用します。定理2のintroProgressは常に1とし、初期表示・リセット・位置編集・係数変更・逆シーク・2Dから3Dへの復帰・定理切り替えでも固定されたQ地形を表示します。定理2には導入のスライダー・再生・スキップを表示しません。

定理3の初期の3Dには、主体の初期位置を中心とする3つの浅い谷を同一平面上に配置します。通常の「再生」で4秒かけて、各谷の中心・幅・深さを連続的に変え、既存の共通地形へモーフィングします。導入が完了すると収束を開始します。一時停止後は変形の途中から再開し、ポップアップでも「導入をスキップ」「変形を最初から再生」を操作できます。モバイル（幅760px以下）では元のグラフ、PCではポップアップで再生します。個人変数r_iと共有表象z_iは別なので、この3つの谷はV_iをz平面上に表示した評価関数ではありません。「概念図」と明記した説明用の配置です。

説明用の各谷の初期の表示高さは −120 max(0, 1−||q−z_i(0)||²/.55²)³ とし、その最小値で一つの面を作ります。重複する谷の深さは加算しません。共通の谷がある場合はsmoothstepの進度で、各中心をLUBへ、半径を√(.85M/係数)へ、深さを120から210へ変えます。3つの中心が一致した終点では元のcompressedHeightと同じ形になります。η=0のポップアップでは共通の谷がないため、各谷の中心・半径を保ち、深さを120から0へ減らして平面につなぎます。この関数は描画だけに使用し、費用・速度場・勾配には渡しません。導入中はモデル時間を0に保ち、主体の座標と合成評価を変更しません。終了後に従来の解析解の再生を開始します。

初期の緑は個人の谷底の目印であり、θ以下の集合ではありません。定理3の導入後は実際のηA_i≤θ_Aをモデル時刻0から表示します。定理2のQ≤θは導入なしで初期状態から表示します。初期段階を「導入をスキップ」で飛ばしても、座標・費用・モデル時間は変わりません。

定理3の導入は一時停止・再開できます。「変形を最初から再生」でモデル時間を0に戻し、導入からやり直せます。通常画面の専用スライダーはモデル時間を0に戻して再生を止め、0〜100％の任意の形を表示します。リセット・初期位置編集・係数変更・定理切り替えで先頭に戻ります。モデル時間を正の値へシークする場合や2Dへの切り替えでは導入を完了扱いにします。時刻0で2Dから3Dに戻した場合は導入を先頭に戻します。再生はユーザー操作で開始するため、動きを減らすOS設定でも明示的に再生した導入を自動省略しません。「導入をスキップ」で手動省略できます。定理3の抽象ポテンシャルの谷底は、結合の分断に関係なくLUBです。

### モデル時間と収束の再生時間

両定理とも収束を0.1倍速で再生します。再生時間s（秒）に対し、解析解に渡すモデル時間はt=0.1sです。主な時間表示とグラフの横軸は収束の再生時間sに統一し、モデル時間tも副表示します。モデルt=1は収束の再生10秒に対応します。定理3の導入の4秒はこの収束再生時間に含めず、導入欄に別の経過秒数を表示します。

費用、解析解、モデル時間についての導関数、指数評価は元の式のままです。モデルの力や係数を弱めず、再生速度と横軸の表示単位だけを変更しています。グラフには全期間の予測曲線をあらかじめ表示し、縦線が現在の再生位置を示します。

導入と収束の時計、アニメーションの停止・再開、表示モードと画面幅に応じた動作は [useCollectivePlayback.ts](../src/hooks/useCollectivePlayback.ts) にまとめています。ポップアップを閉じる／Escapeで時刻と変形の進捗を保って停止し、次の「再生」で途中から再開します。モデル時刻が終端12に達すると停止し、次の「再生」は時刻0から始まります。定理3の3Dでは導入も先頭から再生します。

PCでの再生中に幅760px以下へ切り替えると、ポップアップを閉じ、元の画面へ再生を引き継ぎます。3D表示では変形の進捗も維持します。2D表示へ引き継ぐ場合は、表示されない導入を完了扱いにして、モデル時刻と再生状態を保ったまま収束を続けます。モバイル2Dで時刻0から再生する場合も、導入の4秒を待ちません。

### ポップアップの評価値の比較

PCで「再生」を押すと開くポップアップの3Dは、元の画面と同じ格子・配色・表示圧縮を使い、収束中は地形と高さ変換を固定します。定理3の導入中は、同じ座標枠と高さ変換で説明用の谷を変形します。回転・仰角、θ以下の必要条件の表示、初期位置の輪郭を保持します。定理2の3DはQだけを描くため、個人評価を含む高さの比較は別の積み上げ図で行います。

```text
C_i(t) = V_i(x_i(t)) + Σ_j γ_ij S_ij(x_i(t),x_j(t))
Σ_i C_i(t) = ℒ(t)
C_i(t) ≥ V_i(x_i(t))
```

定理2では主体ごとに初期値と現在値の棒を並べ、個人評価V_iと相互の不整合Σ_jγ_ijS_ijを非負の区画として積み上げます。γ_ijは元の二重和に対応する片方向分を各主体に割り当て、主体間で合計すると社会的費用と一致します。孤立主体の相互作用は0ですが、個人評価V_iは残ります。全主体・初期値・現在値を、同じゼロ基準・再生中に固定した線形目盛りで比較します。したがって、不一致費用を加えると同じ状態の個人評価より低くなるような表示はしません。これは時刻の異なるC_i同士の大小を保証する主張ではありません。

積み上げ図と元画面の時間グラフは、スライダーで設定可能な全辺γ=2の初期合成評価を上限の基準に使います。同じ初期位置・個人状態・θなら、γを0〜2の間で変えても縦軸は一定です。このモデルでは合成評価が初期値以下を保ち、各費用が非負なので、各主体の費用も全期間でこの上限に収まります。数値テストなどでγ>2を渡す場合は、その最大係数を包絡値に使用します。

定理3の比較図は従来どおりηA_iの初期値・現在値・下降量と閾値を表示し、合成評価ℒ_A全体と区別します。ポップアップを閉じるかEscapeを押すと一時停止します。

### 共通の座標枠と集団の重心

定理2・3の3Dは、投影中心(0.5,0.5)・半径1の同じ座標枠を使います。谷底へ自動的に中心を移さず、定理を切り替えても回転・仰角を保持します。投影の倍率と画面内の位置は角度と固定枠から決まり、谷底の位置・結合係数・定理によって変えません。縦方向の費用は従来の圧縮表示のため、谷の見た目の深さによる費用の大小比較は行いません。

黄色のひし形は全3主体の表象の算術平均m(t)=Σᵢzᵢ(t)/3です。黄色の破線は同じ解析解から求めた重心の軌跡で、いずれも基準面に投影します。重心の表示高さを評価値とは扱いません。谷底と基準面の同一座標を結ぶ点線も位置を読むための補助線です。

この具体モデルの結合は対称なので、主体間の力の総和は0です。定理2はṁ=0で、分断時も全3主体の重心は保存されます。定理3はṁ=−η(m−LUB)で、m(t)=LUB+(m(0)−LUB)e^(−ηt)です。η=0では重心は保存されます。重心・軌跡・補助線は観測表示のみで、力や費用を追加しません。

### θ以下の領域を地形上に重ねる

画面の定理3の閾値θ_Aは初期値0.03、スライダーの範囲は0〜0.3（刻み0.01）です。定理2のθは従来どおり初期値0.1、範囲0〜1で、定理を切り替えてもそれぞれの設定を保持します。数値モデルのtheta自体にこのUI上限を課すものではありません。

緑色の領域は、表示している地形の評価項から得られる閾値の範囲です。谷底の評価は0なので、導入を終えた評価地形ではモデル時刻0から表示します。集団全体の合成評価の閾値集合そのものではありません。

- 定理2：注目主体の連結成分のQ(q)≤θ。中心は成分の初期平均、半径は√(θ/λ₂)です。2主体の成分ではλ₂=2γです。非負の各項と社会費用の下界より、ℒ≤θならQ(zᵢ)≤θが必要です。
- 定理3：ηAᵢ(q)≤θ_A。η>0なら中心はLUB、半径は√(2θ_A/η)です。通常画面の地形はAᵢ、ポップアップの地形はηAᵢですが、いずれも同じ閾値の範囲を塗ります。通常画面ではAᵢ≤θ_A/ηと判定し、合成評価に含まれる係数ηを省略しません。

状態領域[0,1]²の外はクリップします。θ=0では谷底の点を表示します。定理2の孤立主体はQ=0なので基準面全域を、定理3のη=0では抽象項による制約がないため地形全域を緑色にします。

これらは合成評価が閾値以下になるための必要条件であり、緑の範囲に入っただけでは十分ではありません。実際のℒ≤θまたはℒ_A≤θ_Aは時間グラフとthresholdReachedで別に判定します。再生によって緑色の領域は変わらず、θや結合・初期位置・世界などの設定変更に追従します。表示の修正であり、費用や速度場への項の追加はありません。
