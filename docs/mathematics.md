# 定理1 Lab の数学モデル

日本語 | [English](mathematics.en.md)

このアプリは、定理1に関わる Lyapunov 型の比較評価を操作して学ぶための教育用モデルです。ここで選んだ二次関数とベクトル場は実装上の具体例であり、苫米地英人博士が人の認知をこの二次元方程式で記述した、という主張ではありません。最適制御問題の数値解や、定理1全体の証明を生成する機能でもありません。

初期表示の比較評価には、有限時間でTCZに入り、内部では速度を引き継いで漂う `drift` を使います。従来の `normal` は別モデルとして保持しています。型の互換性のため、`dynamics` を省略したパラメータの解釈は引き続き `normal` ですが、アプリの `DEFAULT_PARAMETERS` は `drift` を明示します。

## 従来モデル normal のポテンシャルと状態の動き

以下、「有限時間到達と内部漂遊 drift」の節までの軌道・比較・到達に関する説明でいう「通常モード」は、従来の `normal` を指します。現在の初期表示 `drift` の内部挙動は別節で説明します。

状態を p=(x,y)、形状係数を b=`stretch` とし、

```text
V(p) = x² + b y²,   b > 0
Ωθ = {p | V(p) ≤ θ},   θ ≥ 0.25
β = α(1 + δ),   α > 0,   δ = extraDecay ≥ 0
q = (x, √b y)
```

と定義します。Ωθ は楕円（b=1 なら円）です。回転率を ω=`rotation`、90度回転を J(q₁,q₂)=(-q₂,q₁) として、ベクトル場は次式です。

```text
q̇ = -β (V-θ)/(2V) q + ωJq   (V > θ)
q̇ = ωJq                     (V ≤ θ)
```

原点では q̇=0 です。減衰項は境界で連続に零になり、θ>0 のため原点の近傍で割り算は発生しません。この場は局所 Lipschitz 連続です。V は外側で減り、内側で一定なので軌道は有界に保たれ、解をすべての t≥0 へ継続できます。楕円に沿う回転は V を変えません。

時間積分には Euler 法などの刻み幅に依存する近似を使わず、次の解析解を評価します。したがって時間スライダーを往復しても計算誤差が累積しません。

```text
V(t) = θ + (V(0)-θ) exp(-βt)   (V(0)>θ)
V(t) = V(0)                   (V(0)≤θ)
q(t) = √(V(t)/V(0)) R(ωt) q(0) (V(0)>0)
q(t) = 0                      (V(0)=0)
```

R は通常の回転行列です。αを操作すると、この具体的なモデルでは β も変わります。現実の任意のシステムで α を操作できる、という意味ではありません。

## 符号付き残差と正部分

状態座標 y と混同しないよう、ここでは時間の残差を r と書きます。UI の y(t) はこの r(t) に対応します。

```text
r(t) = V(p(t)) - θ
r₊(t) = max(r(t), 0)
```

TCZ の内側では r<0 です。「残り量」として非負のゲージに使うのは r₊ です。内側から始まった場合、本モデルの r は負の定数に留まり、r→0 とはなりません。一方 r₊ は最初から零です。

このモデル全体について正しく使える比較評価は、

```text
0 ≤ r₊(t) = r₊(0) exp(-βt) ≤ r₊(0) exp(-αt)
```

です。外側では r₊=r、ṙ=-βr≤-αr なので、符号付き残差にも同じ比較評価を適用できます。δ=0 のとき実曲線と上限曲線が重なり、δ>0 のとき実曲線の方が速く減少します。`derivative` は符号付き残差の導関数です。内側・境界では零です。

## 集合への距離

一般の V では r₊→0 だけからユークリッド距離の収束を無条件に結論できません。参照資料の誤差境界、または適切なコンパクト性の仮定が必要です。

本モデルでは具体的に次の評価が成り立ちます。m=min(1,b) とすると、外側の点 p に対して p*=√(θ/V(p))p は楕円境界上にあるので、

```text
dist(p,Ωθ) ≤ |p-p*|
            ≤ (√V(p)-√θ)/√m
            = r₊ / ((√V(p)+√θ)√m).
```

最後の式が `distanceBound` です。内側では零です。r₊→0 かつ分母≥√θ√m>0 により距離の収束が従います。これは距離の上限で、楕円への最短距離そのものではありません。回転がある場合、軌道は境界を周回し続けるので、一点への収束も主張しません。

## 有限時間の到達と不変性

外側から始まった本モデルでは、厳密な算術なら任意の有限時刻で r(t)>0 です。境界への距離は零に近づきますが、有限時間内の TCZ 到達は保証しません。「外側に居続けること」と「r→0」は両立します。指数関数 r(0)e^(-βt) がその具体例です。「一定以上の距離を保ち続けること」とは区別します。

内側・境界から出発した場合は V が一定です。そのため Ωθ は前方不変です。この性質は有限時間到達とは別に成り立ちます。条件破壊モードでは、変更後の場に合わせて保証表示と証明ステップを切り替えます。

ブラウザは倍精度浮動小数点で計算するので、非常に小さい残差では V=θ と丸められます。画面上で境界に重なったことや `0.000` と表示されたことは、数学的な有限時間到達を意味しません。内部では残差を指数式から直接計算し、V-θ の差し引きによる桁落ちを避けています。

## 有限時間到達と内部漂遊 drift

この教材独自のモデルは、TCZ外ではポテンシャルを減らして有限時間で入り、TCZ内では単調減少を続けずに漂います。内部の動きは、切替時点の位置と速度を記憶する追加の設計です。定理1や比較原理から内部の漂遊が導かれるとは説明しません。ここでの「速度を引き継ぐ」は軌道の位置・速度が連続という意味であり、物理法則による慣性運動や保存則を主張するものではありません。

変換座標 `q=(x₁,√b x₂)`、`R=√θ`、`β=α(1+δ)>0` を使います。導入区間は

```text
q̇ = -(β/2)q + ωJq,
q(t) = exp(-βt/2) R(ωt)q(0),
V(t) = V(0)exp(-βt).
```

ここで `R(ωt)` は回転行列で、半径の記号Rとは区別します。外から始まった場合のTCZ到達時刻は `t_entry=log(V(0)/θ)/β`、内側または境界から始めた場合は `t_entry=0` です。

漂遊への切替は `|q|=0.6R` で行います。したがって `V(0)>0.36θ` なら `t_drift=log(V(0)/(0.36θ))/β`、すでに `V(0)≤0.36θ` なら最初から漂遊します。`driftTiming()`が両時刻を返します。

切替点をq₀、そのときの導入速度を `v₀=-(β/2)q₀+ωJq₀` として、中心と二つの軸を記憶します。

```text
c = q₀/2,   A = q₀/2,
ν = max(|v₀|/(0.3R), 0.7),   B = v₀/ν,
s = t - t_drift,
q(s) = c + A cos(νs) + B sin(νs),
q̇(s) = -νA sin(νs) + νB cos(νs).
```

`q(0)=q₀`、`q̇(0)=v₀` なので、切替時にも位置と速度が連続です。加速度の連続性までは要求していません。非零初期状態では内部のVが増える時刻と減る時刻を持ち、単調に原点へ下降する軌道にはなりません。ω=0では楕円が線分上の往復運動に退化します。原点から初期化した場合は静止しますが、漂遊中に原点を通過する場合は記憶された速度に従って動き続けます。

漂遊は次の上限によってTCZの内部に留まります。

```text
|c|=|A|≤0.3R,   |B|≤0.3R,
|q(s)| ≤ |c| + √(|A|²+|B|²)
       ≤ (0.3 + √0.18)R < 0.725R < R.
```

導入中にTCZに入った後もVが減り、漂遊中はこの半径上限が成り立つので、一度TCZに入った軌道は出ません。初めからTCZ内の場合も同様です。これは再生後に座標を切り詰める処理ではなく、軌道の式そのものの性質です。

外側では `ẏ=-βV≤-α(V-θ)=-αy` です。到達後は符号付きyが上下しても `y₊=max(y,0)=0` を保つため、全時間で `0≤y₊(t)≤y₊(0)exp(-αt)` が成り立ちます。保証対象はこの正部分です。内部の符号付きyやVが単調減少する保証ではありません。距離は有限時間で零になり、その後も零に留まります。

同じ位置でも、導入中か漂遊中か、どの中心・軸を記憶しているかにより速度が異なります。このためdriftに対して二次元の `field(point,params)` を返すことはできません。`field`、およびそれを使う `potentialDerivative`・`boundaryDerivative` はdriftの場合に例外を投げます。時刻と初期化情報を持つ `velocityAt(time,params)` を使ってください。`Sample.derivative` は常に `2q·q̇` を評価します。固定ベクトル場や固定の散逸ゼロ集合として描かず、`zeroSet='phase-dependent'` とします。

`guarantees()` のdriftに関する判定は、ここに書いた方法で位置・速度・記憶を初期化した軌道族全体への保証です。追加状態に任意の速度を与えてもTCZから出ない、という主張ではありません。このモデルへ位置だけの自律系を前提とするLaSalleの説明を適用しません。

## 条件破壊・前方不変性の実験

どの実験でも、同じ V、Ωθ とユークリッド距離の上限を使います。drift以外の追加した場はすべて二次元の自律系であり、各実験中はパラメータを固定します。

| 場 | V の変化 | αの指数上限 | Ωθの前方不変性 | 全初期状態からのΩθへの収束 |
|---|---|---|---|---|
| normal | 外で V̇=-β(V-θ)、内で0 | 成立 | 成立 | 成立 |
| drift | 外で V̇=-βV、内部漂遊では増減 | 正部分に対して成立 | 許可された初期化で成立 | 成立（有限時間で到達） |
| slow | 外で V̇=-0.35α(V-θ)、内で0 | 不成立 | 成立 | 成立（より遅い指数率） |
| orbit | V̇=0 | 不成立 | 成立 | 不成立 |
| inward | V̇=-βV | 成立 | 成立 | 成立 |
| contained | V̇=βV(1-V/θ) | 成立（外側） | 成立 | 成立 |
| outward | V̇=βV(1-V/K)、K=1.6θ | 不成立 | 不成立 | 不成立 |
| lasalle | V̇=-2βq₂² | 一般には不成立 | 成立 | ω≠0のとき成立 |

ここでβ=α(1+δ)です。「不成立」はその場全体に対する保証がないという意味です。たとえばorbitでも最初からΩθ内なら集合までの距離は零です。`guarantees()`は特定の表示フレームからの推測ではなく、全初期状態に対する場の性質を返します。

`Sample.bound` は全モードで `r₊(0)exp(-αt)` のままです。`comparison=false` の場合は保証を失った**参照曲線**として表示します。slowではこの曲線を超えても集合へ収束するので、「証明条件が失われた」と「収束しない」を区別できます。

inwardでは q̇=-(β/2)q+ωJq とし、V(t)=V(0)exp(-βt) を用います。外から始まれば時刻 log(V(0)/θ)/β で境界へ到達し、その後は内部へ進みます。これは通常モードと異なり、有限時間到達が可能な具体例です。

前方不変性の「外側へ向ける」はcontainedを使います。q̇=(β/2)(1-V/θ)q+ωJqとし、内側では外向き、境界では接線方向、外側では内向きになります。原点以外ではV(t)=θ/[1+(θ/V(0)-1)exp(-βt)]です。0<V(0)<θならVは増加してθへ近づきますが、越えません。原点は静止し、境界からは高さθを保ちます。外側ではV̇=-(βV/θ)(V-θ)≤-α(V-θ)なので、正部分の指数上限も成立します。描画上の位置を切り詰めるのではなく、境界の外向き成分が0になる場そのものを使っています。

境界で外向きの成分が残って不変性を失う例は、条件を壊すテーマのoutwardで比較できます。

前方不変性の画面はnormal・inward・containedだけを選べ、初期条件はTCZの内側または境界に限定します。ドラッグ、座標入力、θやbの変更で初期点が外側になるときは、初期点を同じ方向の境界へ写します。この操作は初期条件の設定時のみで、再生中の軌道を切り詰める処理ではありません。比較評価・条件を壊す・LaSalleにはこの初期位置制限を適用しません。

outwardでは q̇=(β/2)(1-V/K)q+ωJq とします。原点は静止し、それ以外では

```text
V(t) = K / (1 + (K/V(0)-1) exp(-βt)) → K > θ.
```

境界V=θで V̇=βθ(1-1/1.6)>0 となり、非零の内部初期点が外へ出ます。Vはmax(V(0),K)以下なので、画面を飛び出して無限に発散するモデルではありません。V̇=0となる集合は原点と楕円V=Kです。`zeroSet='origin-and-ellipse'`はこれを表します。

`boundaryDerivative()`は境界点(√θ,0)におけるV̇です。LaSalleモードの境界上では場所により値が違うので、任意の点での評価には`potentialDerivative(point, params)`を使います。`viewportPotential()`は将来すべての時刻のVを押さえる値で、外向き実験のKも含みます。

## LaSalle の参考モデル

このモデルは数値計算とテスト用に保持していますが、現在の図示メニューからは選択できません。

本教材独自の線形モデルとして、変換座標で次を用います。

```text
q̇₁ = ω q₂
q̇₂ = -ω q₁ - d q₂,   d=β>0
V = q₁²+q₂²
V̇ = -2d q₂² ≤ 0
```

Vが減らない点の集合Eはq₂=0という直線です。しかしω≠0なら、E上の原点以外でq̇₂=-ωq₁≠0となり、軌道はその直線から離れます。したがってEに含まれる最大不変集合は原点だけです。初期値の劣位集合 `{V≤V(0)}` はコンパクトかつ前方不変であり、この集合上でLaSalleの不変原理を適用するとq(t)→0が従います。原点はΩθ内なので集合への収束も従います。

ω=0ならq₁は一定で、q₂だけが指数減衰します。このときE全体が不変であり、極限点は(q₁(0),0)です。q₁(0)²>θならΩθへは収束しません。「V̇=0の集合」と「その中に留まり続けられる最大不変集合」を区別する実験です。

軌道は2×2行列の指数関数で厳密評価し、過減衰・臨界減衰・不足減衰を分けて計算します。過減衰では発散する双曲線関数と減衰指数の積を避け、二つの減衰指数を直接使います。ω=0の解も分岐して扱います。

このLaSalleの説明は本教材の自律的な線形モデルに限定しています。時間依存のVや一般の制御問題へ、仮定を確認せず適用するものではありません。

## 実装の範囲

### 3D地形への表示

表示する曲面は `(x₁, x₂, h(V(x₁,x₂)))` です。表示専用の単調非減少な高さ変換hで、中央の窪みが周囲の平面に滑らかにつながる格子面を作ります。平面部分は複数のVを同じ表示高さへ圧縮するので、高さそのものをVの数値や等高線と読み替えることはできません。実際のVは数値・時間グラフ・2D等高線で確認できます。

具体的には描画範囲の基準値をMとして `h(V) = -210 max(0, 1 - V/(0.85M))³` を使います。V ≥ 0.85Mでは平面、中心では窪みの底になり、接続はC²連続です。Mは初期値・閾値・軌道全体の上界に合わせて決め、再生中は固定します。

縦軸は可視化のためのもので、状態変数や運動方程式を追加したものではありません。状態点・軌跡・TCZ境界にはすべて同じhを適用し、数値計算には元のVを使います。TCZ境界は `V=θ`、表示高さはh(θ)です。時空の歪みに似た形は視覚上の表現で、物理的な時空や重力を計算するものではありません。

通常モードで初期状態が外側の場合、状態点は平面から窪みへ進み、V=θの境界へ近づきます。くぼみの最底点 `V=0` へ強制的に移動させる表示にはしていません。内部から始まった場合は、通常モードでは高さを保って移動します。画面の立体表示はSVGへの投影で、視点の変更や2D表示との切り替えは計算結果に影響しません。別の場を選んだ場合は、それぞれの解析解に従うVの変化を表示します。

単一主体・静的ポテンシャルを対象とします。積分コストの最小化から瞬間的な減少条件を導出せず、性質が解析的に確認できる具体的な場を構成しています。複数主体、抽象化ポテンシャルは後続実装です。

ユニットテストは軌道の有限差分と場の一致、ポテンシャル微分、パラメータ組合せごとの比較評価、内部・境界の不変性、非円形の軌道、距離上限と長時間の挙動を検証します。
